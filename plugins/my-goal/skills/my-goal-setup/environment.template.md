## Model routing + context discipline (include in any agent-spawning prompt)

{{TIER_BLOCK}}

**Universal, regardless of plan:**

- **Right-size the model to the job.** Top-tier reasoning on a format check is a sledgehammer driving
  a finishing nail.
- **Scope per agent beats model tier.** Prefer narrow finisher and gap-fill briefs — "these files
  exist, complete X, one closing pass" — over fleets of from-scratch agents. One concept pushed deep
  beats N parallel shallow builds.
- **Diagnose before escalating.** Lackluster output has three causes and only one is fixed by a
  bigger model: (a) the spec was ambiguous → sharpen the brief, same model, nearly free; (b) effort
  was too low → raise effort or add a pass, same model, cheap; (c) a genuine capability ceiling →
  now escalate the tier. Never skip the diagnosis; never grind a capability failure at the same tier
  either.
- **Verification routing.** Checks with a defined pass/fail spec run on small or mid models in
  bounded loops. Only the final would-they-ship-it judgment needs the top tier.
